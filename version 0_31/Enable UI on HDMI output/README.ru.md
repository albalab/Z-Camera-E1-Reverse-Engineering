# Включение пользовательского интерфейса на выходе HDMI

Этот патч включает отображение пользовательского интерфейса камеры на выходе HDMI.

## Описание

По умолчанию Z-Camera E1 отображает свой пользовательский интерфейс на основе Qt только на встроенном ЖК-экране. Этот патч изменяет маршрутизацию вывода изображения, чтобы включить пользовательский интерфейс (слой OSD) на выходе HDMI, позволяя вам видеть систему меню камеры и настройки на внешнем HDMI-мониторе.

## Что он делает

- Включает вывод OSD (экранное меню) через HDMI
- Настраивает путь отображения для маршрутизации элементов интерфейса на HDMI
- Устанавливает HDMI в качестве основного выхода дисплея
- Включает микшер OSD для вывода HDMI

## Как использовать

1. Скопируйте файл `autoexec.ash` в корневую директорию вашей micro-SD карты
2. Вставьте micro-SD карту в вашу Z-Camera E1
3. Включите камеру
4. Пользовательский интерфейс должен теперь отображаться на вашем HDMI-мониторе

## Примечание

Этот патч предназначен для версии прошивки 0.31. Используемые адреса памяти специфичные для этой версии и могут не работать с другими версиями прошивки.

## Совместимость

- Версия прошивки: 0.31
- Может быть объединен с другими патчами (например, патчи битрейта)
- **Совместим с патчем "HDMI color space fix"** - Эти патчи хорошо работают вместе, обеспечивая как вывод интерфейса, так и правильное цветовое пространство на HDMI

## Устранение неполадок

Если пользовательский интерфейс не появляется на HDMI:
- Убедитесь, что кабель HDMI правильно подключен перед включением камеры
- **Рекомендуется:** Объедините этот патч с патчем "HDMI color space fix" для достижения наилучших результатов
- Проверьте, что ваш HDMI-монитор поддерживает выходное разрешение камеры
- При объединении нескольких патчей убедитесь, что строки исправления цветового пространства HDMI включены в ваш объединенный файл autoexec.ash
